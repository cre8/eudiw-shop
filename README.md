# eudiw.shop

The unofficial gift shop for the European Digital Identity Wallet: a parody homepage with selectively disclosed prices.

Static site in `public/`, deployed with Cloudflare Pages.

## Cloudflare Pages settings

| Setting | Value |
| --- | --- |
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `public` |

## Local preview

```bash
npx wrangler pages dev
```
